## Descripción del proyecto

El SGVI busca centralizar el registro de productos, clientes, ventas y movimientos de inventario de un negocio, mantener el control de las existencias y generar reportes que apoyen la toma de decisiones.

## Flujo de trabajo

- Ningún cambio se realiza directamente sobre `main`.
- Cada actividad se desarrolla en una rama `feature/nombre-tarea` (o `fix/...` para correcciones).
- Los commits siguen la convención `docs:`, `feat:`, `fix:`, `refactor:`, `test:`.
- Los cambios se integran mediante Pull Request.
