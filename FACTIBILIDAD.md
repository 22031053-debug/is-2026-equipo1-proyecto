# Estudio de Factibilidad - Sistema de Gestión de Ventas e Inventario (SGVI)

**Fecha:** 2026-10-19  
**Equipo:** Equipo 1  
**Integrantes:** Cristian Maldonado

## 1. Factibilidad Técnica

- **Infraestructura y Lenguajes:** El proyecto se gestionará mediante Git y GitHub. El desarrollo del sistema contempla módulos para registrar productos, clientes y ventas, controlar el inventario y consultar reportes. Las tecnologías definitivas de implementación deberán confirmarse conforme avance el diseño técnico.
- **Experiencia y Capacidades:** El responsable cuenta con experiencia académica en programación, bases de datos, control de versiones y documentación de proyectos de software. El desarrollo individual permite mantener una visión integral del sistema, aunque limita la capacidad disponible para implementar y verificar varias tareas simultáneamente.
- **Riesgos Tecnológicos:** Los principales riesgos son los errores en la lógica de ventas e inventario, la pérdida o inconsistencia de datos, los problemas de integración entre módulos y las limitaciones de tiempo. Se reducirán mediante control de versiones, validaciones, pruebas y documentación técnica.

## 2. Factibilidad Económica

- **Recursos de Cómputo Requeridos:** Se requiere una computadora, conexión a internet, Visual Studio Code y Git. GitHub se utilizará para alojar el repositorio. Se priorizarán herramientas gratuitas o de código abierto.
- **Estimación de Costos de Desarrollo:** El desarrollo se realizará como proyecto académico individual. Para calcular el costo de referencia, se utilizará la fórmula: horas estimadas de trabajo × costo estimado por hora. No se asigna un importe monetario definitivo porque aún no se han establecido ambos valores.
- **Análisis de Costo-Beneficio:** El proyecto permite practicar análisis, diseño, desarrollo y gestión de software. Se espera que el SGVI facilite la organización de productos, clientes, ventas e inventario, y reduzca errores derivados del registro manual. El beneficio académico y operativo esperado justifica el uso de herramientas disponibles sin licencias de pago.

## 3. Factibilidad Operativa

- **Impacto en el Usuario Final:** El SGVI busca centralizar la información de productos, clientes, ventas e inventario para facilitar su consulta y seguimiento.
- **Facilidad de Adopción y Usabilidad:** Se buscará una interfaz clara, formularios con campos comprensibles, validaciones de entrada y mensajes de error útiles. Las funciones se organizarán de acuerdo con las tareas principales del usuario.
- **Cumplimiento Legal y Normativo:** Se evitará incluir credenciales, contraseñas o tokens en el repositorio. Los datos personales se manejarán únicamente cuando sean necesarios para las funciones definidas, con acceso controlado y respeto a la privacidad. Se verificarán las licencias de las dependencias utilizadas.
